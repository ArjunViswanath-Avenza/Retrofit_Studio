# tools

`vineflower-1.11.1.jar` — Java decompiler used by the **Java JARs** view (Fabric workspace).
Run by `server/decompiler.js` through the Vite dev server (`npm run dev`); needs Java 11+ on the PATH
(or set `RETROFIT_JAVA` to a java executable).
